# Release `v1.1.0` (`2026-11-14`)

**reflbo-nm-epd-420 `v1.1.0`** brings Europe-wide open precipitation radar via **DWD OpenData WMS** alongside a repaired global **RainViewer** fallback, instant `KEY` preset switching with an auto-hiding compact toast, faster cold sync & Wi-Fi status visibility, modular **SX1262 / MeshCore** drivers with persistent NVS secrets & key rotation, drift-compensated sleep timing, and LittleFS health recovery.

---

## Highlights & Improvements

### Precipitation Radar (DWD OpenData + RainViewer)
- **DWD GeoServer WMS Integration (`radar_dwd.c`):** Replaced region-limited ČHMÚ radar (`radar_chmu.c`) with open **DWD OpenData WMS**:
  - `Radar_rv_product_1x1km_ger` (`1×1 km` 5-minute radar composite) across Central Europe and Western Poland.
  - `Icon-eu_reg00625_fd_sl_TOTPREC01H` (hourly precipitation forecast/composite) across the rest of Europe and Poland.
- **1/2/4-Bit Indexed PNG Support:** Extended `components/png/png.c` to unpack 1-, 2-, and 4-bit palette PNG images (`PNG_PALETTE`) required by DWD ICON-EU tiles while preserving fast streaming decode in PSRAM.
- **Repaired RainViewer Global Fallback:** Fixed `Universal Blue` low-dBZ / light-rain color & alpha classification and replaced coarse coverage assumptions with exact bounding-box and zoom-scale checks (`radar_frame_covers()`).
- **Live Location & Zoom responsiveness:** Automatically invalidates mismatched frames, guards against stale in-flight fetches on rapid Web UI changes, and triggers immediate radar refresh when radar location/zoom changes (`app_sync_radar_due_now()`).

### Boot Sync, Wi-Fi Status & UI Responsiveness
- **Faster Cold Reset Sync:** Eliminated the redundant blank EPD commit in cold `display_init()`, restored the `8 s` per-network STA join timeout in `netmgr`, and applied SNTP time via an early `on_time` callback immediately upon time synchronization before weather/radar steps finish.
- **Always-Accurate Top-Left Wi-Fi Icon:** Displays the Wi-Fi indicator in the status bar whenever STA IP connectivity is active (including active syncs and station Web UI sessions), remaining hidden on the **Focus** preset and Setup QR screen.
- **Instant `KEY` Switching (`0 ms`) & Compact 1-Frame Toast:** Removed the `KEY` double-click wait (moving auto-cycle toggling cleanly into the on-device Menu and Web UI Presets page), shrunk the preset overlay banner to a `22 px` bottom pill (`gfx_font_sans_bold_16`) drawn in the same EPD frame as the new preset, and auto-clears the banner cleanly after ~2.5 s.
- **Fast `Focus` Exit & BLE Resume:** Skips duplicate wake pre-renders on `KEY` wake and defers Focus exit radio/Wi-Fi tear-down/bring-up behind the target preset render, while cleanly restoring MeshCore BLE advertising on non-Focus `KEY` wakes.

### SX1262 LoRa, MeshCore & Security
- **Modular Radio & Protocol Architecture:** Extracted pure-C `sx1262_radio` (`SPI3_HOST` driver with `board_spi3_lock()` shared-bus mutex and `TF_CS`/`LORA_NSS` idle-high protection) and `meshcore_node` protocol engine out of `lora_widget.c`.
- **NVS Secrets & Node Identity Rotation:** Stored custom `lora.channel_psk` (`lora_psk`) and persistent CSPRNG Ed25519 node seed / 6-digit BLE PIN (`lora_seed`, `lora_pin`) in NVS `secrets` (keeping secrets out of JSON settings & backups; preserving legacy MAC-derived identity on upgraded devices until rotated via `POST /api/lora/rekey` or CLI `reset-identity`).
- **Hybrid DIO1 Light-Sleep Policy & Split Fields:** Supports LoRa wake-on-RX during battery light sleep while staying awake when USB-tethered or BLE-connected (`power_lora_wake_lock()`), and exposes live LoRa dashboard fields (`lora.nodes`, `lora.msgs`, `lora.rssi`, `lora.snr`, `lora.last_msg`) with fixed negative SNR formatting.

### Display, Timekeeping & Storage Hardening
- **Hardware Abstraction & Sub-Zero EPD Compensation:** Added `ssd1683.h` / `ssd1683_frame.h` / `sw_rtc.h` headers and signed two's-complement register `0x1A` temperature encoding (`ssd1683_encode_temp_reg()`) below `15 °C`.
- **Sub-Second Sleep Drift Compensation:** Enabled software drift correction down to `1 ms` and drift-compensated RTC sleep intervals (`timekeeping_sleep_us_until()`, `timekeeping_trim_sleep_us()`), avoiding `tv_usec` truncation across minute wakes.
- **LittleFS Self-Healing & Diagnostics:** Added mount write-probe recovery (`storage_is_healthy()`, `storage_get_usage()`) and `storage [status | format]` USB console command.

## Flashing (`COM` / USB-Serial-JTAG)

### Option A: Automated Windows Script (Recommended — preserves NVS & LittleFS config)
```powershell
.\release\flash.ps1 -Port COM15
```
Or double-click `release\flash.bat` and enter your COM port (`COM15`).

### Option B: Unified Full 16 MB Image (`0x0`, fresh / factory flash)
```sh
python -m esptool --chip esp32s3 --port COM15 --baud 921600 \
  --before default-reset --after watchdog-reset write_flash \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 reflbo-nm-epd-420-full-16MB-v1.1.0.bin
```

### Option C: Web UI OTA Update (existing `reflbo` installation)
Upload `reflbo-nm-epd-420-v1.1.0.bin` via the Web Configurator **Firmware** page (`http://192.168.4.1` or `reflbo-XXXX.local`).

> **Note for ESP32-S3 USB-Serial-JTAG:** When leaving ROM download mode (`BOOT` held on reset), use `--after watchdog-reset` (esptool >= v4.7 / v5.x) or power-cycle the board with `PWR` so the ESP32-S3 re-samples strapping pins and boots the application.

## Package Contents & Integrity
Checksums for every binary and flash helper are published in `SHA256SUMS.txt`:
- `reflbo-nm-epd-420-full-16MB-v1.1.0.bin` — Unified factory flash image starting at `0x0` (`bootloader.bin` + `partition-table.bin` + `ota_data_initial.bin` + `reflbo-nm-epd-420-v1.1.0.bin`).
- `reflbo-nm-epd-420-v1.1.0.bin` — Application binary (`ota_0` @ `0x20000` / Web UI OTA).
- `bootloader.bin`, `partition-table.bin`, `ota_data_initial.bin` — Individual boot/partition components for modular reflashing without overwriting NVS (`0x9000`) or LittleFS (`0x830000`).
- `flash.ps1`, `flash.bat` — Windows flash scripts with UTF-8 encoding & `watchdog-reset` handling.
- `SHA256SUMS.txt` — SHA-256 verification sums.
