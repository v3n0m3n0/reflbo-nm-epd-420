# Release `v1.2.0` (`2026-11-19`)

**reflbo-nm-epd-420 `v1.2.0`** overhauls the `#lora` Web UI and interactive map with **Poland voivodeship boundaries**, improves on-device **Weather** readability with `48 px` icons, adds multi-gradient **RainViewer** precipitation tiers, hardens **cold-boot auto-sync**, enables one-press **`USER` (`KEY`) dismissal** of the `Wi-Fi Setup` screen, and tunes the preset switch toast to a precise **`1.5 s` post-refresh** duration.

---

## Highlights & Improvements

### `#lora` Web UI & Poland Voivodeship Map
- **Poland Administrative Level-1 Boundaries (`MAP_LINE_ADMIN1`):** Extended `assets/map/map.bin` and `tools/gen_map.py` with Natural Earth v5.1.2 (`ne_10m_admin_1_states_provinces_lines.geojson`, `ADM0_A3 == "POL"`, 34 polylines / 725 points covering all 16 voivodeships), cleanly skipped on the 400×300 e-paper renderer (`map_draw.c`) and reserved in `GET /api/lora/map` (`LORA_MAP_LINES_RESERVE = 3200 B`) so dense boundaries never starve `towns[]`.
- **Interactive Geo Map & Polar Radar Overhaul (`web/app.js`, `web/style.css`):** Fixed flat `[kind, lat0, lon0, ...]` polyline decoding with distinct styling for country borders, coastlines, and voivodeships; moved non-GPS contacts to a clickable `.map-nogps-strip` opening `#lora-map-inspector`; unified `ResizeObserver` logical sizing with 1:1 drag panning and collision-avoided node labels; added distance labels in `Polar Radar`.
- **Responsive `#lora` Subtabs & Controls:** Added subtabs (`All sections`, `Chat`, `Map & Nodes`, `Settings & Channels`, `CLI`) with `hidden="until-found"`, `@container`-responsive `Channels 0–7` table, normalized decimal comma input (`,` → `.`) for `airtime_factor`, `.danger` styling for destructive actions, wrapped 64-hex public keys, and clean polling stop on HTTP `401`.

### On-Device E-Paper UI & Rain Radar
- **Accurate `#lora` Status Bar:** Shows `Ch: All` when multiple channels are configured (or the single active channel's name), `Rpt: off` when `client_repeat` is disabled vs real `Fwd: <n>` forwarded count when enabled, and dynamically spaces Line 2 so `RSSI` / `SNR` / `NF` never clip.
- **`Weather` Preset `48 px` Icons & Larger Digits:** Upgraded bottom `s1` / `s2` tiles to `UI_SIZE_M` with ink-cropped `48 px` temperature and humidity icons beside `num_cb_48` digits (`ui_widget_draw_iconic()`, automatic fallback to `24 px` for wide values).
- **Multi-Gradient RainViewer Clouds:** Re-tiered RainViewer *Universal Blue* palette (`#004768..#007fb4` → `moderate`, `#ff8100..#ffb700` → `heavy`, `#0088bf..#88ddee` → `light`) to align with DWD precipitation tiers on 1-bit e-paper.
- **DMA-Safe Partial Refresh:** Preserved fast partial refreshes across preset/menu navigation while retaining `0x1A` temperature register writes in `part_refresh` and adding a static `DMA_ATTR` bounce buffer (`s_dma_bounce[2048]`) in `st7305.c` to eliminate `ESP_ERR_NO_MEM` SPI DMA errors during concurrent Wi-Fi/HTTPS syncs.

### Cold-Boot Sync, `Wi-Fi Setup` UX & Preset Toast Timing
- **Reliable Cold-Boot Auto-Sync:** Added an automatic second full-scan pass inside `netmgr` `join_saved()` (`JOIN_RETRY_PAUSE_MS = 1500 ms`) within the `25 s` sync join budget, shortened the first `SYNC_NEED_TIME` retry from `15 min` to `1 min` (`{ 1, 15, 30, 60 }` min) in `sync_plan.c`, and guarded `app_sync.c` `started` / `ended` timestamps against `uint32_t` underflow (`2106-02-07`) on uncalibrated clocks.
- **One-Press `Wi-Fi Setup` Dismissal:** Pressing `USER` (`KEY` short) on the `Wi-Fi Setup` screen now calls `app_config_exit()` and returns immediately to the dashboard (moving QR code switching in AP+URL mode to `BOOT` short), suppresses the misleading `"Wi-Fi off"` toast when Wi-Fi stays active in `always` mode, and updates EN/CS footer hints.
- **`1.5 s` Post-Commit Preset Toast:** Added `app_ui_toast_arm_ms(..., APP_UI_PRESET_TOAST_MS = 1500)` and shifted toast expiration timing in `app_ui_render()` to start **after** `display_commit(false)` completes, ensuring consistent on-glass visibility regardless of partial or 20th-frame full refresh latency.

## Flashing (`COM` / USB-Serial-JTAG)

### Option A: Automated Windows Script (Recommended — preserves NVS & LittleFS config)
```powershell
.\release\flash.ps1 -Port COM15
```
Or double-click `release\flash.bat` and enter your COM port (`COM15`).

### Option B: Unified 16 MB Factory Image (`0x0`)
```sh
python -m esptool --chip esp32s3 --port COM15 --baud 921600 \
  --before default-reset --after watchdog-reset write_flash \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 release/reflbo-nm-epd-420-full-16MB-v1.2.0.bin
```
